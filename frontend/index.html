规则说明

  • 接单：只有持有 Agent ID 的地址能接单；发单方不能接自己的任务。页面按钮会按持有情况禁用并写明原因，合约也会再次校验，无法绕过。
  • 交付：接单方提交交付内容（链接或内容哈希）。
  • 验收 / 拒绝：只有发单方能操作。验收后托管报酬放款给接单方；拒绝后任务回到“进行中”，接单方可重新交付（交付内容会被清空）。
  • 超时退款：过了验收截止时间仍未验收的任务，任何人可触发退款，报酬退回发单方；已完成的任务永远不可退款。
  • 取消：发单方仅在任务无人接单时可取消，锁定报酬退回发单方。
  • 合约 Owner 权限：Owner 不能动托管资金、不能暂停合约、不能更换支付代币或 Agent ID 合约，也不能修改别人的任务；资金只通过验收放款、退款、取消三条路径流出。
  • 合约地址按网络自动选择（见 frontend/config.js）：本地 31337、测试网 97、主网 56；切到其他网络会明确提示不支持。
